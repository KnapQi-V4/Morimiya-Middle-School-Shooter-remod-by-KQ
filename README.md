# Morimiya Middle School Shooting (Remod by KQ)

Versi modifikasi dan lokalisasi bilingual (English & Bahasa Indonesia) untuk game RPG Maker MV / NW.js **Morimiya Middle School Shooting** (森宮中学校銃乱射事件, v1.2b).

---

## 🌟 Fitur Baru (New Features)

### 1. Dual Language System (English & Bahasa Indonesia)
- Pilihan bahasa dapat diganti kapan saja secara instan melalui menu **Options (Pengaturan)**:
  - **`Language: English`**
  - **`Bahasa: Indonesia`**
- Menerjemahkan seluruh UI, layar opsi, database senjata, perlengkapan, keahlian, cutscene cerita, balon percakapan/teriakan, petunjuk manual (*tips*), dan prestasi (*achievements*).

### 2. Perbaikan Subtitle (Subtitle Cutoff Fix)
- Mengatasi masalah balon dialog karakter yang sebelumnya terpotong di tepi layar.
- Menggunakan kalkulasi lebar teks dinamis berbasis piksel font serta pembatasan batas layar (*screen boundary clamping*).

### 3. Sistem Cheat Terintegrasi (Built-in Cheats)
Tersedia menu toggle di menu **Options (Pengaturan)** serta tombol hotkey langsung dalam permainan:
- **Cheat: SP Tak Terbatas** (*Infinite SP*): Uang/SP selalu berada di angka 9.999.999 dan tidak berkurang.
- **Cheat: Amunisi Tak Terbatas** (*Infinite Ammo*): Senjata tidak kehabisan peluru saat ditembakkan dan seluruh magazen cadangan terisi penuh.
- **Cheat: Bom Tak Terbatas** (*Infinite Bombs*): Persediaan bom pipa/granat selalu 99.
- **Cheat: Kebal / Darah Inf** (*Infinite Health / God Mode*): Pemain kebal terhadap tembakan polisi, serangan jarak dekat guru, tidak mengalami *Game Over* / penangkapan, dan stamina selalu penuh.

#### Tombol Pintas (Hotkey Cheat):
- Tekan **`9`** atau **`F8`** di keyboard saat bermain untuk mengaktifkan / menonaktifkan semua cheat sekaligus (*Master Cheat Toggle*).
- Opsi cheat juga tersedia langsung di menu Komputer kamar tidur karakter.

## 🎮 Kontrol Permainan (Controls)

| Tombol | Fungsi |
| :--- | :--- |
| **W, A, S, D** / Tombol Panah | Bergerak |
| **Shift** | Berlari (Lari menguras stamina) |
| **Spasi (Space)** | Menembak / Menyerang |
| **E** | Mode Membidik (Meningkatkan akurasi) |
| **R** | Mengisi Ulang Peluru (*Reload*) |
| **Q** | Beralih Senjata Utama & Pistol Sampingan |
| **G** | Melempar Bom Pipa / Granat (Tahan untuk jarak lebih jauh) |
| **V** | Serangan Cepat Pisau (*Quick Melee*) |
| **3** | Menghunus Senjata Jarak Dekat |
| **1 / 2** | Memilih Senjata Utama / Pistol Sampingan |
| **F** | Mengganti Target Sasaran |
| **C** | Mengganti Mode Tembak (*Semi / Burst / Auto*) |
| **X / Esc** | Batal / Menu |
| **9 / F8** | **Master Cheat Toggle** (Aktifkan Semua Cheat) |

---

## 🚀 Cara Menjalankan Game (How to Play)
Jalankan file **`Game.exe`** di folder utama untuk langsung memainkan game di Windows.
